# Платформа для велопроката

Публичная веб-презентация для владельцев велопрокатов.

Статический сайт: HTML, CSS и изображения. Сборка и сервер приложений не нужны.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`.

## Локальный просмотр

```sh
python -m http.server 8080
```

Откройте http://localhost:8080.

Изображения байков обработаны по предоставленным референсам. Иллюстрации и макеты не являются документацией технических характеристик или подтверждением готовности интеграций.
